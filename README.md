# nodejs
### 2. Примеры MongoDB-запросов
Создайте коллекцию `books`. Каждый документ должен иметь структуру:

```json
{
  "title": "string",
  "description": "string",
  "authors": "string"
}
```

#### 2.1 Вставка данных

```js
// Вставляем сразу два документа
db.books.insertMany([
  {
    title: "Преступление и наказание",
    description: "Роман Ф. М. Достоевского о нравственном перерождении",
    authors: "Фёдор Достоевский"
  },
  {
    title: "Мастер и Маргарита",
    description: "Фантастико-философский роман Михаила Булгакова",
    authors: "Михаил Булгаков"
  }
]);
```

#### 2.2 Поиск по `title`

- **Точный поиск**:
  ```js
  db.books.find(
    { title: "Мастер и Маргарита" },
    { _id: 0, title: 1, description: 1, authors: 1 }
  );
  ```
- **Поиск по подстроке** (регулярное выражение):
  ```js
  db.books.find(
    { title: /Мастер/i },
    { _id: 0, title: 1, description: 1, authors: 1 }
  );
  ```

#### 2.3 Обновление полей

- **По конкретному `_id`**:
  ```js
  db.books.updateOne(
    { _id: ObjectId("60d5f483f2954f3d2c8b4567") },
    { $set: {
        description: "Новое описание книги",
        authors: "Иван Иванов"
      }
    }
  );
  ```

- **Массовое обновление** всех книг одного автора:
  ```js
  db.books.updateMany(
    { authors: "Михаил Булгаков" },
    { $set: { description: "Обновленное описание для всех книг Булгакова" } }
  );
  ```
